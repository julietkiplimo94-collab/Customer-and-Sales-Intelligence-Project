# Customer and Sales BI: Kenyan Retail Chain

Capstone project by Juliet Kiplimo. Last updated 18 November 2026.

> **The sales data in this repository is synthetic.** Every row of the stores, products, customers, promotions, transactions and transaction lines tables is generated by `src/generate_data.py`. No real retailer, shopper or sale is described. The CPI, county population and payment-usage tables are real, extracted from public KNBS, FinAccess and Communications Authority reports.

## What this project does

It builds a retail analytics dataset for a fictional 30-store supermarket chain in Kenya (stores across 12 counties, 400 products, 8,000 customers and a year of transactions with promotions and payment methods) and joins it to the real KNBS Consumer Price Index. The questions, success measures and limitations are in [`docs/problem_statement.md`](docs/problem_statement.md).

An earlier version of this project analysed a mobile-money platform's fees and agents, and read its data from a local `J:\` drive that was not in the repository. This version replaces that with a retail brief, uses relative paths only, and commits the raw data.

```bash
git clone <your-repo-url>

python src/generate_data.py      # optional: the CSVs are already committed
python src/validate_data.py      # expect: 27/27 checks passed
```

Options: `--seed 42` (default), `--transactions 60000`, `--customers 8000`.

For the notebooks:

```bash
pip install -r requirements.txt
jupyter lab
```

Read the data with relative paths so it works on any machine:

```python
from pathlib import Path
import pandas as pd

ROOT = Path.cwd().parent if Path.cwd().name == "notebooks" else Path.cwd()
RAW = ROOT / "data" / "raw"

transactions = pd.read_csv(RAW / "synthetic" / "transactions.csv", parse_dates=["transaction_date"])
cpi = pd.read_csv(RAW / "external" / "cpi_monthly_2024.csv")
```

Join sales to CPI on month:

```python
transactions["month"] = transactions["transaction_date"].dt.strftime("%Y-%m")
sales_cpi = transactions.merge(cpi, on="month", how="left")
```

### Assumptions built into the data

These are set at the top of `src/generate_data.py`. Anything an analysis finds about them was put there by the generator and is not a finding about the real market.

1. **Prices follow the real KNBS index.** Each product's price moves with its COICOP division, chained from the published monthly % changes, with January 2024 = 1.0. Food categories use the Food index, toiletries use Personal Care, and cleaning products use Household Equipment.
2. **Units respond to price.** Each category has an assumed elasticity between −0.3 (staples) and −1.0 (snacks).
3. **Discounts lift units.** Units rise by 1.5 × the discount fraction.
4. **Payment mix depends on the county.** Cash share falls as county mobile money use rises. Card share rises with bank use and is highest in hypermarkets. The mobile money share is split about 92.4% M-Pesa and 7.6% Airtel Money (T-Kash is ignored: its share rounds to 0.0%).
5. **Inflation nudges payments.** Each point of YoY inflation above the 2024 average adds 1.5 points to the cash share. Set `CASH_INFLATION_SENSITIVITY = 0` to remove this.
6. **Seasonality.** More shopping from Friday to Sunday (Saturday highest), at month-end, in December, and around public holidays and Black Friday.
7. **Promotions.** 23 promotions: 11 seasonal or category events and 12 monthly loyalty-only payday offers.

### Reproducibility

The generator uses only the Python standard library and a seeded `random.Random`. Running it twice with the same seed, parameters and Python version gives byte-identical files; `data/raw/synthetic/generation_log.json` records each file's SHA-256 checksum. Standard-library random streams are stable across recent Python 3 releases but are not guaranteed to be, so a different Python version could in principle change the numbers.

## Known limitations

- Sales are synthetic, and 60,000 transactions is a sample, not the volume of a real 30-store chain.
- CPI is national and measured in urban centres, so it does not describe every county.
- Division indices are chained from rounded monthly changes.
- May 2024 CPI was revised after the first release (139.85 to 139.64). The revised figure is used for the overall index; the May division changes come from the original release.
- County payment rates are from 2021; sales are for 2024.
- The public holiday list is a draft and must be verified.
